# Modul 4 – Automasi Konfigurasi dan Verifikasi Perangkat Jaringan dengan Bash dan Python

## Capaian Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
- memahami konsep automasi konfigurasi pada server atau perangkat jaringan;
- menggunakan tool Linux untuk mengirim perintah dan memverifikasi hasil konfigurasi;
- membuat Bash Script untuk automasi verifikasi jaringan;
- membuat Python Script menggunakan `paramiko` atau `netmiko` untuk pengelolaan perangkat;
- mendokumentasikan hasil konfigurasi dan verifikasi secara sistematis.

## Pendahuluan
Setelah mempelajari command Linux dasar, monitoring jaringan, serta akses remote pada modul sebelumnya, langkah berikutnya adalah menerapkan automasi pada proses konfigurasi dan verifikasi perangkat jaringan. Dalam praktik nyata, administrator sering melakukan pekerjaan yang berulang, seperti memeriksa interface, melihat konfigurasi IP, membaca routing table, atau mengambil backup konfigurasi.

Apabila pekerjaan tersebut dilakukan satu per satu secara manual, waktu yang dibutuhkan akan semakin besar seiring bertambahnya jumlah server atau perangkat jaringan. Oleh karena itu, automasi menjadi pendekatan penting agar pekerjaan konfigurasi dan verifikasi dapat dilakukan lebih cepat, konsisten, dan terdokumentasi. Modul ini memperkenalkan penggunaan tool Linux, Bash, dan Python untuk kebutuhan tersebut.

## Bagian 1 – Tool Linux untuk Konfigurasi dan Verifikasi Jaringan

### 1. `ssh`
`ssh` digunakan untuk masuk ke host remote dan menjalankan konfigurasi atau verifikasi dari jarak jauh.

**Fungsi utama:**
- mengakses perangkat atau server secara aman;
- mengirim perintah konfigurasi;
- mengambil output verifikasi dari host remote.

**Contoh penggunaan:**
```bash
ssh admin@192.168.1.10
```

**Menjalankan perintah verifikasi secara langsung:**
```bash
ssh admin@192.168.1.10 "ip addr && ip route"
```

**Penjelasan:**
- perintah pertama membuka sesi interaktif;
- perintah kedua langsung menampilkan hasil konfigurasi IP dan routing dari host remote.

---

### 2. `scp`
`scp` digunakan untuk mengirim atau mengambil file konfigurasi dari host remote.

**Fungsi utama:**
- backup konfigurasi;
- distribusi file konfigurasi;
- pengambilan file hasil log atau verifikasi.

**Contoh penggunaan:**
```bash
scp router_backup.cfg admin@192.168.1.10:/home/admin/backup/
```

```bash
scp admin@192.168.1.10:/home/admin/backup/router_backup.cfg ./
```

**Penjelasan:**
- contoh pertama mengirim file backup ke host remote;
- contoh kedua mengambil file backup ke komputer lokal.

---

### 3. `diff`
`diff` digunakan untuk membandingkan dua file konfigurasi.

**Fungsi utama:**
- melihat perubahan konfigurasi sebelum dan sesudah modifikasi;
- mendukung audit konfigurasi;
- membantu validasi hasil backup.

**Contoh penggunaan:**
```bash
diff config_lama.txt config_baru.txt
```

**Penjelasan:**
Perintah ini menampilkan perbedaan isi antara dua file sehingga administrator dapat mengetahui bagian konfigurasi yang berubah.

---

### 4. `tee`
`tee` digunakan untuk menyimpan output perintah ke file sekaligus menampilkannya ke terminal.

**Fungsi utama:**
- dokumentasi hasil verifikasi;
- pencatatan output command;
- pembuatan log sederhana.

**Contoh penggunaan:**
```bash
ip addr | tee hasil_ip.txt
```

```bash
ssh admin@192.168.1.10 "ip route" | tee routing_remote.txt
```

**Penjelasan:**
Dengan `tee`, output perintah tetap tampil di layar dan juga tersimpan pada file.

---

### 5. `grep`
`grep` digunakan untuk memfilter bagian penting dari konfigurasi atau output verifikasi.

**Fungsi utama:**
- mencari alamat IP tertentu;
- menemukan status interface;
- memfilter konfigurasi agar lebih mudah dibaca.

**Contoh penggunaan:**
```bash
ip addr | grep inet
```

```bash
ssh admin@192.168.1.10 "ip addr" | grep inet
```

**Penjelasan:**
Tool ini membantu administrator fokus pada baris penting tanpa harus membaca seluruh output.

---

### 6. `hostnamectl`
`hostnamectl` digunakan untuk melihat atau mengatur identitas host pada sistem Linux.

**Fungsi utama:**
- melihat nama host sistem;
- membantu verifikasi target perangkat;
- memastikan koneksi dilakukan ke host yang benar.

**Contoh penggunaan:**
```bash
hostnamectl
```

```bash
ssh admin@192.168.1.10 "hostnamectl"
```

**Penjelasan:**
Informasi hostname berguna untuk membedakan beberapa server atau perangkat saat praktikum automasi.

---

### 7. `ip link`
`ip link` digunakan untuk menampilkan status interface jaringan pada level link.

**Fungsi utama:**
- melihat interface UP atau DOWN;
- membantu diagnosis interface fisik dan virtual;
- memverifikasi hasil konfigurasi antarmuka.

**Contoh penggunaan:**
```bash
ip link
```

```bash
ip link show eth0
```

**Penjelasan:**
Jika interface berada pada status `DOWN`, maka layanan jaringan pada interface tersebut kemungkinan belum aktif.

## Bagian 2 – Bash Script

Bash Script dapat digunakan untuk mengotomasi verifikasi konfigurasi dasar dari satu atau beberapa host.

### Script 1 – Verifikasi Informasi Dasar Host Remote
Script berikut menjalankan beberapa perintah verifikasi pada host remote.

```bash
#!/bin/bash

user="admin"
host="192.168.1.10"

echo "===== VERIFIKASI HOST REMOTE ====="
ssh ${user}@${host} "hostnamectl; echo ''; ip addr; echo ''; ip route"
```

**Nama file yang disarankan:** `verifikasi_remote.sh`

**Cara menjalankan:**
```bash
chmod +x verifikasi_remote.sh
./verifikasi_remote.sh
```

**Penjelasan:**
- script menampilkan nama host, alamat IP, dan routing table;
- cocok digunakan sebagai pemeriksaan awal setelah konfigurasi.

---

### Script 2 – Backup dan Bandingkan Konfigurasi
Script berikut mensimulasikan backup konfigurasi dari host remote lalu membandingkan dua file hasil backup.

```bash
#!/bin/bash

user="admin"
host="192.168.1.10"
remote_file="/home/admin/config.txt"
local_old="config_old.txt"
local_new="config_new.txt"

scp ${user}@${host}:${remote_file} ${local_new}

echo "===== HASIL PERBANDINGAN ====="
diff ${local_old} ${local_new}
```

**Nama file yang disarankan:** `backup_diff.sh`

**Cara menjalankan:**
```bash
chmod +x backup_diff.sh
./backup_diff.sh
```

**Penjelasan:**
- file konfigurasi terbaru diambil dari host remote;
- `diff` digunakan untuk melihat perubahan konfigurasi.

## Bagian 3 – Python Script

Python memberikan kemampuan yang lebih fleksibel untuk automasi konfigurasi dan verifikasi, terutama ketika perangkat atau host yang diperiksa berjumlah banyak.

### Script 1 – Verifikasi Host Remote dengan Paramiko
Script berikut login ke host remote dan menjalankan beberapa perintah verifikasi.

```python
import paramiko

host = "192.168.1.10"
username = "admin"
password = "password"
commands = ["hostnamectl", "ip addr", "ip route"]

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())

try:
    client.connect(hostname=host, username=username, password=password, timeout=5)
    for command in commands:
        print(f"===== Menjalankan: {command} =====")
        stdin, stdout, stderr = client.exec_command(command)
        print(stdout.read().decode())
except Exception as e:
    print(f"Koneksi gagal: {e}")
finally:
    client.close()
```

**Nama file yang disarankan:** `verifikasi_paramiko.py`

**Instalasi pustaka:**
```bash
pip install paramiko
```

**Cara menjalankan:**
```bash
python3 verifikasi_paramiko.py
```

**Penjelasan:**
- script menjalankan beberapa perintah secara berurutan;
- hasil tiap perintah ditampilkan sehingga memudahkan verifikasi host.

---

### Script 2 – Verifikasi Perangkat Jaringan dengan Netmiko
Script berikut digunakan untuk masuk ke perangkat jaringan dan memeriksa status interface.

```python
from netmiko import ConnectHandler

device = {
    "device_type": "cisco_ios",
    "host": "192.168.1.1",
    "username": "admin",
    "password": "admin123",
}

commands = [
    "show ip interface brief",
    "show running-config | include hostname",
    "show ip route"
]

try:
    connection = ConnectHandler(**device)
    for command in commands:
        print(f"===== Menjalankan: {command} =====")
        output = connection.send_command(command)
        print(output)
        print()
    connection.disconnect()
except Exception as e:
    print(f"Koneksi ke perangkat gagal: {e}")
```

**Nama file yang disarankan:** `verifikasi_netmiko.py`

**Instalasi pustaka:**
```bash
pip install netmiko
```

**Cara menjalankan:**
```bash
python3 verifikasi_netmiko.py
```

**Penjelasan:**
- `show ip interface brief` digunakan untuk melihat status interface;
- `show running-config | include hostname` untuk memastikan identitas perangkat;
- `show ip route` untuk memverifikasi routing.
