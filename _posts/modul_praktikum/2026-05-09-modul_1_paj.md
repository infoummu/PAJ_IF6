# Modul 1 – Dasar Linux Command, bash dan python untuk Jaringan

## Capaian Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
- memahami fungsi dasar beberapa tool Linux untuk administrasi dan troubleshooting jaringan;
- menjalankan perintah dasar seperti `ping`, `arp`, `grep`, `nmap`, dan `find`;
- menggunakan layanan akses jaringan seperti `SSH`, `FTP`, dan `Telnet` pada level dasar;
- membuat automasi sederhana menggunakan Bash Script;
- membuat Python Script sederhana untuk membantu pekerjaan jaringan.

## Pendahuluan
Dalam administrasi jaringan, kemampuan menggunakan command line Linux merupakan keterampilan dasar yang sangat penting. Banyak pekerjaan seperti pengujian konektivitas, pencarian file konfigurasi, pemindaian host, maupun akses ke perangkat jaringan dilakukan melalui terminal.

Selain itu, pekerjaan jaringan modern tidak berhenti pada penggunaan perintah secara manual. Administrator juga perlu mengotomasi tugas-tugas berulang menggunakan *script*, baik dengan Bash maupun Python. Oleh karena itu, modul pertama ini difokuskan pada pengenalan tool Linux dasar untuk jaringan, dilanjutkan dengan penerapan sederhana menggunakan Bash dan Python.

## Bagian 1 – Tool Linux untuk Jaringan

### 1. `ping`
`ping` digunakan untuk menguji konektivitas jaringan antara komputer lokal dengan host tujuan menggunakan protokol ICMP.

**Fungsi utama:**
- mengecek apakah host aktif;
- mengukur waktu tempuh paket (*latency*);
- membantu diagnosis gangguan jaringan dasar.

**Contoh penggunaan:**
```bash
ping 8.8.8.8
```

```bash
ping -c 4 google.com
```

**Penjelasan:**
- `-c 4` artinya mengirim 4 paket saja;
- jika host merespons, maka koneksi dasar tersedia.

---

### 2. `arp`
`arp` digunakan untuk melihat atau memanipulasi tabel ARP, yaitu pasangan antara alamat IP dan alamat MAC pada jaringan lokal.

**Fungsi utama:**
- melihat pemetaan IP ke MAC address;
- membantu analisis komunikasi dalam LAN.

**Contoh penggunaan:**
```bash
arp -a
```

**Penjelasan:**
Perintah ini menampilkan daftar host yang pernah dikenali pada jaringan lokal beserta alamat fisiknya.

> Catatan: pada sebagian distribusi Linux modern, fungsi ini sering digantikan oleh perintah `ip neigh`.

Contoh alternatif:
```bash
ip neigh
```

---

### 3. `grep`
`grep` digunakan untuk mencari teks tertentu pada file atau output perintah lain.

**Fungsi utama:**
- memfilter output;
- mencari konfigurasi tertentu dalam file;
- mempermudah analisis hasil perintah jaringan.

**Contoh penggunaan:**
```bash
ip addr | grep inet
```

```bash
grep "nameserver" /etc/resolv.conf
```

**Penjelasan:**
- `grep inet` memfilter hanya baris yang berisi alamat IP;
- `grep "nameserver"` menampilkan konfigurasi DNS.

---

### 4. `nmap`
`nmap` digunakan untuk melakukan pemindaian jaringan dan port pada host target.

**Fungsi utama:**
- mengetahui host aktif;
- memeriksa port terbuka;
- identifikasi layanan jaringan secara dasar.

**Contoh penggunaan:**
```bash
nmap 192.168.1.1
```

```bash
nmap -sV 192.168.1.1
```

**Penjelasan:**
- `-sV` digunakan untuk mendeteksi versi layanan yang berjalan pada port target.

> Gunakan `nmap` hanya pada jaringan/lab yang diizinkan.

---

### 5. `find`
`find` digunakan untuk mencari file atau direktori berdasarkan nama, tipe, atau kriteria tertentu.

**Fungsi utama:**
- mencari file konfigurasi jaringan;
- membantu administrasi file pada sistem Linux.

**Contoh penggunaan:**
```bash
find /etc -name "*.conf"
```

```bash
find /home -name "*.log"
```

**Penjelasan:**
Perintah ini sangat berguna saat mencari file konfigurasi atau log yang terkait dengan layanan jaringan.

---

### 6. `ssh`
`ssh` (*Secure Shell*) digunakan untuk mengakses host atau perangkat jaringan secara aman dari jarak jauh.

**Fungsi utama:**
- login ke server jarak jauh;
- menjalankan perintah dari host lain;
- administrasi perangkat jaringan dengan aman.

**Contoh penggunaan:**
```bash
ssh user@192.168.1.10
```

```bash
ssh admin@router-lab
```

**Penjelasan:**
Setelah berhasil login, pengguna dapat menjalankan administrasi sistem secara remote melalui terminal terenkripsi.

---

### 7. `ftp`
`ftp` digunakan untuk transfer file antara client dan server menggunakan protokol FTP.

**Fungsi utama:**
- mengunggah file;
- mengunduh file;
- latihan konsep layanan file transfer klasik.

**Contoh penggunaan:**
```bash
ftp 192.168.1.20
```

**Contoh perintah di dalam sesi FTP:**
```bash
ls
get file.txt
put laporan.txt
bye
```

**Penjelasan:**
FTP secara bawaan tidak aman karena data dan kredensial dapat dikirim tanpa enkripsi. Gunakan untuk lingkungan praktikum/lab saja.

---

### 8. `telnet`
`telnet` digunakan untuk akses terminal jarak jauh atau pengujian port layanan TCP.

**Fungsi utama:**
- menguji apakah port TCP terbuka;
- mengenalkan protokol akses jarak jauh lama;
- membantu diagnosis koneksi layanan.

**Contoh penggunaan:**
```bash
telnet 192.168.1.30 23
```

```bash
telnet smtp.gmail.com 25
```

**Penjelasan:**
Saat ini Telnet jarang digunakan untuk akses administrasi karena tidak aman, tetapi masih berguna untuk pengujian koneksi port pada praktikum.

## Bagian 2 – Bash Script

Bash Script dapat digunakan untuk mengotomasi perintah Linux yang sering dijalankan berulang. Pada bagian ini ditunjukkan dua contoh script sederhana.

### Script 1 – Monitoring Konektivitas Host
Script berikut melakukan ping ke beberapa host dan menampilkan statusnya.

```bash
#!/bin/bash

hosts=("8.8.8.8" "1.1.1.1" "google.com")

for host in "${hosts[@]}"; do
    if ping -c 2 "$host" > /dev/null 2>&1; then
        echo "[OK] $host dapat dijangkau"
    else
        echo "[GAGAL] $host tidak dapat dijangkau"
    fi
done
```

**Nama file yang disarankan:** `cek_host.sh`

**Cara menjalankan:**
```bash
chmod +x cek_host.sh
./cek_host.sh
```

**Penjelasan:**
- `hosts=(...)` menyimpan daftar host;
- `ping -c 2` mengirim 2 paket ICMP;
- output dialihkan ke `/dev/null` agar tampilan lebih bersih;
- hasil ditampilkan dalam format status sederhana.

---

### Script 2 – Pemindaian Port Dasar dan Pencarian Log
Script berikut menggunakan `nmap` dan `grep` untuk menyimpan hasil scan lalu mencari port yang berstatus terbuka.

```bash
#!/bin/bash

target="127.0.0.1"
outfile="hasil_scan.txt"

nmap $target > $outfile

echo "Hasil scan disimpan pada $outfile"
echo "Port yang terbuka:"
grep "open" $outfile
```

**Nama file yang disarankan:** `scan_port.sh`

**Cara menjalankan:**
```bash
chmod +x scan_port.sh
./scan_port.sh
```

**Penjelasan:**
- `nmap $target > $outfile` menyimpan hasil scan ke file;
- `grep "open" $outfile` menampilkan hanya baris port yang terbuka.

## Bagian 3 – Python Script

Python banyak digunakan untuk automasi jaringan karena sintaksnya sederhana dan memiliki banyak pustaka seperti `paramiko` dan `netmiko`.

### Script 1 – Ping Host dengan Python
Contoh berikut memanggil perintah `ping` dari Python menggunakan modul `subprocess`.

```python
import subprocess

hosts = ["8.8.8.8", "1.1.1.1", "google.com"]

for host in hosts:
    result = subprocess.run([
        "ping", "-c", "2", host
    ], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)

    if result.returncode == 0:
        print(f"[OK] {host} dapat dijangkau")
    else:
        print(f"[GAGAL] {host} tidak dapat dijangkau")
```

**Nama file yang disarankan:** `ping_hosts.py`

**Cara menjalankan:**
```bash
python3 ping_hosts.py
```

**Penjelasan:**
- `subprocess.run()` digunakan untuk mengeksekusi perintah Linux dari Python;
- `returncode == 0` menandakan perintah berhasil.

---

### Script 2 – SSH Sederhana dengan Paramiko
Script berikut menunjukkan contoh koneksi SSH sederhana menggunakan pustaka `paramiko`.

```python
import paramiko

host = "192.168.1.10"
username = "user"
password = "password"

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())

try:
    client.connect(hostname=host, username=username, password=password, timeout=5)
    stdin, stdout, stderr = client.exec_command("uname -a")
    print("Output perintah dari host remote:")
    print(stdout.read().decode())
except Exception as e:
    print(f"Koneksi gagal: {e}")
finally:
    client.close()
```

**Nama file yang disarankan:** `ssh_paramiko.py`

**Cara instal pustaka:**
```bash
pip install paramiko
```

**Cara menjalankan:**
```bash
python3 ssh_paramiko.py
```

**Penjelasan:**
- `paramiko.SSHClient()` membuat client SSH;
- `exec_command()` menjalankan perintah pada host remote;
- output dibaca dan ditampilkan ke terminal lokal.

---

### Catatan Tambahan tentang Netmiko
Untuk automasi perangkat jaringan seperti router atau switch, pustaka `netmiko` sering digunakan karena lebih praktis dibanding `paramiko` untuk perangkat Cisco, MikroTik, Juniper, dan vendor lain.

Contoh singkat:

```python
from netmiko import ConnectHandler

device = {
    "device_type": "cisco_ios",
    "host": "192.168.1.1",
    "username": "admin",
    "password": "admin123",
}

connection = ConnectHandler(**device)
output = connection.send_command("show ip interface brief")
print(output)
connection.disconnect()
```

Instalasi:
```bash
pip install netmiko
```
