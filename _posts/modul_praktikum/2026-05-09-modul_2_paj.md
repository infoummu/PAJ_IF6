## Bagian 1 – Tool Linux untuk Analisis dan Monitoring Jaringan

### 1. `ip addr`
Perintah `ip addr` digunakan untuk menampilkan informasi alamat IP pada setiap interface jaringan di Linux.

**Fungsi utama:**
- melihat interface yang tersedia;
- mengetahui alamat IPv4 dan IPv6;
- memeriksa status interface aktif atau tidak.

**Contoh penggunaan:**
```bash
ip addr
```

```bash
ip addr show eth0
```

**Penjelasan:**
- `ip addr` menampilkan semua interface jaringan;
- `ip addr show eth0` hanya menampilkan informasi interface `eth0`.

---

### 2. `ip route`
Perintah `ip route` digunakan untuk menampilkan routing table pada sistem Linux.

**Fungsi utama:**
- melihat jalur pengiriman paket;
- mengetahui default gateway;
- membantu diagnosis kesalahan routing.

**Contoh penggunaan:**
```bash
ip route
```

**Contoh output penting:**
```bash
default via 192.168.1.1 dev eth0
192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.10
```

**Penjelasan:**
- baris `default via ...` menunjukkan gateway utama;
- baris jaringan lokal menunjukkan subnet yang langsung terhubung.

---

### 3. `ss`
Perintah `ss` digunakan untuk melihat socket atau koneksi jaringan yang sedang aktif pada sistem.

**Fungsi utama:**
- memeriksa port yang sedang listen;
- memantau koneksi TCP/UDP aktif;
- menggantikan fungsi `netstat` pada banyak distribusi Linux modern.

**Contoh penggunaan:**
```bash
ss -tuln
```

```bash
ss -tn
```

**Penjelasan:**
- `-t` untuk TCP;
- `-u` untuk UDP;
- `-l` untuk port yang sedang listen;
- `-n` agar alamat dan port ditampilkan dalam bentuk numerik.

---

### 4. `netstat`
`netstat` merupakan tool klasik untuk melihat koneksi jaringan, tabel routing, dan statistik interface.

**Fungsi utama:**
- melihat koneksi aktif;
- menampilkan routing table;
- memeriksa port terbuka.

**Contoh penggunaan:**
```bash
netstat -tuln
```

```bash
netstat -rn
```

**Penjelasan:**
- `-tuln` menampilkan port TCP/UDP yang aktif;
- `-rn` menampilkan tabel routing dalam format numerik.

> Catatan: pada sistem Linux modern, `ss` dan `ip route` lebih sering digunakan daripada `netstat`.

---

### 5. `nslookup`
`nslookup` digunakan untuk melakukan query DNS terhadap nama domain atau alamat IP.

**Fungsi utama:**
- memeriksa resolusi nama domain;
- menguji DNS server;
- membantu diagnosis masalah DNS.

**Contoh penggunaan:**
```bash
nslookup google.com
```

```bash
nslookup google.com 8.8.8.8
```

**Penjelasan:**
- perintah pertama menggunakan DNS server default sistem;
- perintah kedua secara khusus menggunakan DNS server `8.8.8.8`.

---

### 6. `dig`
`dig` adalah tool DNS yang lebih lengkap dibanding `nslookup`.

**Fungsi utama:**
- melihat jawaban DNS secara detail;
- memeriksa record seperti `A`, `MX`, `NS`, dan `TXT`;
- menganalisis respon DNS secara teknis.

**Contoh penggunaan:**
```bash
dig google.com
```

```bash
dig google.com MX
```

**Penjelasan:**
- `dig google.com` menampilkan record default, biasanya `A`;
- `dig google.com MX` menampilkan mail exchanger domain tersebut.

---

### 7. `host`
Perintah `host` digunakan untuk mencari informasi DNS secara cepat dan ringkas.

**Fungsi utama:**
- melakukan lookup domain ke IP;
- melakukan reverse lookup IP ke nama host.

**Contoh penggunaan:**
```bash
host google.com
```

```bash
host 8.8.8.8
```

**Penjelasan:**
- perintah pertama melakukan forward lookup;
- perintah kedua melakukan reverse lookup.

---

### 8. `cat` dan `grep` untuk file konfigurasi jaringan
Walaupun `cat` dan `grep` bukan tool jaringan khusus, keduanya sangat penting untuk membaca file konfigurasi sistem.

**File yang umum diperiksa:**
- `/etc/resolv.conf` untuk DNS;
- `/etc/hosts` untuk pemetaan host lokal;
- file konfigurasi jaringan lain sesuai distribusi Linux.

**Contoh penggunaan:**
```bash
grep nameserver /etc/resolv.conf
```

```bash
grep 127.0.0.1 /etc/hosts
```

**Penjelasan:**
- `grep nameserver` menampilkan DNS resolver yang digunakan sistem;
- `grep 127.0.0.1 /etc/hosts` menampilkan entri loopback lokal.

---

### 9. `traceroute`
`traceroute` digunakan untuk melihat lintasan paket menuju host tujuan melalui beberapa router.

**Fungsi utama:**
- mengetahui jalur paket;
- mengidentifikasi hop yang bermasalah;
- membantu diagnosis latency atau routing antar jaringan.

**Contoh penggunaan:**
```bash
traceroute google.com
```

**Penjelasan:**
Perintah ini menampilkan daftar hop yang dilalui paket dari host lokal ke host tujuan.

## Bagian 2 – Bash Script

Bash Script sangat berguna untuk menggabungkan beberapa perintah monitoring jaringan menjadi satu proses otomatis.

### Script 1 – Audit Konfigurasi Jaringan Dasar
Script berikut menampilkan alamat IP, default gateway, dan DNS resolver.

```bash
#!/bin/bash

echo "===== INFORMASI INTERFACE ====="
ip addr | grep inet

echo ""
echo "===== ROUTING TABLE ====="
ip route

echo ""
echo "===== DNS RESOLVER ====="
grep nameserver /etc/resolv.conf
```

**Nama file yang disarankan:** `audit_jaringan.sh`

**Cara menjalankan:**
```bash
chmod +x audit_jaringan.sh
./audit_jaringan.sh
```

**Penjelasan:**
- `ip addr | grep inet` menampilkan alamat IP yang aktif;
- `ip route` menampilkan rute dan gateway;
- `grep nameserver /etc/resolv.conf` menampilkan DNS resolver sistem.

---

### Script 2 – Monitoring Port dan DNS
Script berikut memeriksa port yang sedang listen dan melakukan uji resolusi domain.

```bash
#!/bin/bash

domain="google.com"

echo "===== PORT YANG AKTIF ====="
ss -tuln

echo ""
echo "===== UJI DNS ====="
nslookup $domain
```

**Nama file yang disarankan:** `monitor_port_dns.sh`

**Cara menjalankan:**
```bash
chmod +x monitor_port_dns.sh
./monitor_port_dns.sh
```

**Penjelasan:**
- `ss -tuln` menampilkan port yang sedang aktif/listen;
- `nslookup $domain` menguji apakah sistem dapat melakukan resolusi DNS.

## Bagian 3 – Python Script

Python memudahkan pembacaan output sistem dan pengolahan hasil monitoring jaringan secara lebih terstruktur.

### Script 1 – Membaca Informasi IP dan Routing dengan Python
Script berikut menjalankan perintah Linux lalu menampilkan hasilnya ke terminal.

```python
import subprocess

print("===== INFORMASI IP =====")
ip_result = subprocess.run(["ip", "addr"], capture_output=True, text=True)
print(ip_result.stdout)

print("===== INFORMASI ROUTING =====")
route_result = subprocess.run(["ip", "route"], capture_output=True, text=True)
print(route_result.stdout)
```

**Nama file yang disarankan:** `info_jaringan.py`

**Cara menjalankan:**
```bash
python3 info_jaringan.py
```

**Penjelasan:**
- `capture_output=True` digunakan untuk menyimpan output perintah;
- `text=True` membuat output dibaca sebagai string.

---

### Script 2 – Pemeriksaan DNS dan Port dengan Python
Script berikut memeriksa DNS sebuah domain dan menampilkan port listen dari sistem.

```python
import subprocess

print("===== CEK DNS =====")
dns_result = subprocess.run(["nslookup", "google.com"], capture_output=True, text=True)
print(dns_result.stdout)

print("===== PORT LISTEN =====")
port_result = subprocess.run(["ss", "-tuln"], capture_output=True, text=True)
print(port_result.stdout)
```

**Nama file yang disarankan:** `cek_dns_port.py`

**Cara menjalankan:**
```bash
python3 cek_dns_port.py
```

**Penjelasan:**
- script ini menggabungkan pengecekan DNS dan monitoring port;
- hasilnya dapat digunakan untuk dokumentasi maupun troubleshooting awal.
