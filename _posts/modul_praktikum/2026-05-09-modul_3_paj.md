# Modul 3 – Automasi Akses Jaringan dengan SSH, FTP, Telnet, Bash, dan Python

## Capaian Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
- memahami konsep akses jarak jauh pada sistem dan perangkat jaringan;
- menggunakan `ssh`, `scp`, `ftp`, dan `telnet` untuk kebutuhan administrasi dasar;
- membedakan metode akses yang aman dan tidak aman;
- membuat Bash Script sederhana untuk automasi akses remote;
- membuat Python Script sederhana untuk koneksi dan eksekusi perintah jarak jauh.

## Pendahuluan
Pada administrasi jaringan, banyak pekerjaan dilakukan dari jarak jauh tanpa harus datang langsung ke perangkat atau server. Teknologi seperti SSH memungkinkan administrator menjalankan perintah, mengambil file, dan melakukan konfigurasi dari terminal lokal ke host remote dengan aman.

Selain SSH, protokol klasik seperti FTP dan Telnet juga penting untuk dipahami, terutama dalam konteks pembelajaran sejarah protokol jaringan, pengujian koneksi, dan lingkungan laboratorium. Modul ini membahas penggunaan tool akses remote secara manual, lalu dilanjutkan dengan automasi sederhana menggunakan Bash dan Python.

## Alat dan Bahan
- Sistem operasi Linux
- Terminal / shell
- Koneksi jaringan lokal atau internet
- Host remote / server uji / VM / router simulasi
- Python 3
- Pustaka Python standar
- (Opsional) `paramiko`, `netmiko`
- Akun login ke host uji

## Bagian 1 – Tool Linux untuk Akses Jaringan Jarak Jauh

### 1. `ssh`
`ssh` (*Secure Shell*) digunakan untuk mengakses host remote secara aman melalui koneksi terenkripsi.

**Fungsi utama:**
- login ke server atau perangkat jaringan;
- menjalankan perintah dari jarak jauh;
- administrasi sistem dan jaringan secara aman.

**Contoh penggunaan:**
```bash
ssh user@192.168.1.10
```

```bash
ssh admin@router-lab
```

**Menjalankan perintah remote tanpa login interaktif:**
```bash
ssh user@192.168.1.10 "hostname && ip addr"
```

**Penjelasan:**
- `ssh user@host` digunakan untuk membuka sesi remote;
- perintah dalam tanda kutip dapat dieksekusi langsung dari terminal lokal.

---

### 2. `scp`
`scp` (*Secure Copy Protocol*) digunakan untuk menyalin file antara komputer lokal dan host remote melalui SSH.

**Fungsi utama:**
- mengirim file ke server;
- mengambil file dari server;
- transfer file dengan enkripsi.

**Contoh penggunaan:**
```bash
scp laporan.txt user@192.168.1.10:/home/user/
```

```bash
scp user@192.168.1.10:/etc/hosts ./hosts-backup
```

**Penjelasan:**
- contoh pertama mengirim file ke host remote;
- contoh kedua mengambil file dari host remote ke komputer lokal.

---

### 3. `sftp`
`sftp` adalah metode transfer file interaktif yang berjalan di atas SSH.

**Fungsi utama:**
- upload dan download file dengan aman;
- navigasi direktori remote;
- pengelolaan file sederhana pada host remote.

**Contoh penggunaan:**
```bash
sftp user@192.168.1.10
```

**Contoh perintah di dalam sesi SFTP:**
```bash
ls
pwd
put file.txt
get backup.cfg
bye
```

**Penjelasan:**
`sftp` lebih aman dibanding FTP karena menggunakan kanal terenkripsi berbasis SSH.

---

### 4. `ftp`
`ftp` digunakan untuk transfer file melalui protokol FTP.

**Fungsi utama:**
- mengunggah file;
- mengunduh file;
- memahami konsep file transfer klasik.

**Contoh penggunaan:**
```bash
ftp 192.168.1.20
```

**Contoh perintah di dalam sesi FTP:**
```bash
ls
get data.txt
put config.txt
bye
```

**Penjelasan:**
FTP tidak mengenkripsi kredensial dan data sehingga sebaiknya hanya digunakan pada lingkungan praktikum atau lab.

---

### 5. `telnet`
`telnet` adalah protokol akses terminal lama yang juga sering digunakan untuk menguji koneksi TCP ke port tertentu.

**Fungsi utama:**
- login ke perangkat lama pada lab;
- menguji apakah port layanan dapat diakses;
- belajar tentang protokol akses remote generasi awal.

**Contoh penggunaan:**
```bash
telnet 192.168.1.30
```

```bash
telnet 192.168.1.30 23
```

```bash
telnet smtp.gmail.com 25
```

**Penjelasan:**
- Telnet tidak aman karena tidak mengenkripsi data;
- masih berguna untuk pengujian port TCP dalam praktikum.

---

### 6. `wget` dan `curl`
Walaupun bukan tool akses shell remote, `wget` dan `curl` sering digunakan untuk mengambil file, menguji layanan HTTP/HTTPS, dan berinteraksi dengan server.

**Fungsi utama:**
- mengunduh file konfigurasi atau backup;
- menguji respons web service;
- mendukung automasi jaringan berbasis API.

**Contoh penggunaan:**
```bash
wget http://example.com/file.txt
```

```bash
curl http://example.com
```

```bash
curl -I https://example.com
```

**Penjelasan:**
- `wget` lebih fokus untuk mengunduh file;
- `curl` lebih fleksibel untuk request HTTP dan API;
- `curl -I` menampilkan hanya header HTTP.

---

### 7. `ssh-keygen`
`ssh-keygen` digunakan untuk membuat pasangan kunci SSH publik dan privat.

**Fungsi utama:**
- mendukung login SSH tanpa password;
- meningkatkan keamanan dan efisiensi login;
- fondasi automasi remote berbasis kunci.

**Contoh penggunaan:**
```bash
ssh-keygen -t rsa -b 2048
```

**Penjelasan:**
Perintah ini membuat pasangan kunci SSH yang dapat digunakan untuk autentikasi ke server tanpa memasukkan password setiap kali login.

---

### Ringkasan Bagian 1
Tool yang digunakan pada modul ini berfokus pada akses dan transfer data jarak jauh:
- `ssh` untuk akses remote aman;
- `scp` dan `sftp` untuk transfer file terenkripsi;
- `ftp` untuk file transfer klasik;
- `telnet` untuk akses remote lama dan uji port;
- `wget` dan `curl` untuk interaksi dengan layanan berbasis file atau web;
- `ssh-keygen` untuk autentikasi berbasis kunci.

## Bagian 2 – Bash Script

Pada administrasi jaringan, banyak tugas remote dapat diotomasi dengan Bash Script, misalnya mengambil informasi dari beberapa host atau menyalin file konfigurasi.

### Script 1 – Menjalankan Perintah SSH ke Host Remote
Script berikut menjalankan perintah sederhana pada host remote menggunakan SSH.

```bash
#!/bin/bash

user="user"
host="192.168.1.10"

ssh ${user}@${host} "hostname; whoami; ip addr | grep inet"
```

**Nama file yang disarankan:** `remote_info.sh`

**Cara menjalankan:**
```bash
chmod +x remote_info.sh
./remote_info.sh
```

**Penjelasan:**
- script membuka koneksi SSH ke host tujuan;
- beberapa perintah dijalankan sekaligus pada host remote;
- hasilnya ditampilkan di terminal lokal.

---

### Script 2 – Backup File dengan SCP
Script berikut mengirim file lokal ke host remote sebagai simulasi backup konfigurasi.

```bash
#!/bin/bash

source_file="config_backup.txt"
user="user"
host="192.168.1.10"
destination="/home/user/backup/"

scp $source_file ${user}@${host}:$destination

echo "Backup selesai dikirim ke ${host}:${destination}"
```

**Nama file yang disarankan:** `backup_scp.sh`

**Cara menjalankan:**
```bash
chmod +x backup_scp.sh
./backup_scp.sh
```

**Penjelasan:**
- `scp` digunakan untuk mengirim file secara aman;
- script dapat dikembangkan untuk mengirim banyak file sekaligus.

## Bagian 3 – Python Script

Python sangat berguna untuk automasi akses jaringan karena dapat menangani koneksi, autentikasi, parsing output, dan pengolahan data secara lebih fleksibel dibanding Bash.

### Script 1 – Eksekusi Perintah Remote dengan Paramiko
Contoh berikut menunjukkan cara login SSH dan menjalankan perintah dari Python.

```python
import paramiko

host = "192.168.1.10"
username = "user"
password = "password"

client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())

try:
    client.connect(hostname=host, username=username, password=password, timeout=5)
    stdin, stdout, stderr = client.exec_command("hostname && ip addr | grep inet")
    print("Output dari host remote:")
    print(stdout.read().decode())
except Exception as e:
    print(f"Koneksi gagal: {e}")
finally:
    client.close()
```

**Nama file yang disarankan:** `ssh_remote.py`

**Instalasi pustaka:**
```bash
pip install paramiko
```

**Cara menjalankan:**
```bash
python3 ssh_remote.py
```

**Penjelasan:**
- `paramiko` digunakan untuk koneksi SSH dari Python;
- `exec_command()` mengeksekusi perintah pada host remote;
- hasil dibaca dari `stdout`.

---

### Script 2 – Automasi Perangkat Jaringan dengan Netmiko
Contoh berikut menunjukkan penggunaan `netmiko` untuk login ke perangkat jaringan dan menjalankan perintah.

```python
from netmiko import ConnectHandler

device = {
    "device_type": "cisco_ios",
    "host": "192.168.1.1",
    "username": "admin",
    "password": "admin123",
}

try:
    connection = ConnectHandler(**device)
    output = connection.send_command("show ip interface brief")
    print("Output perangkat jaringan:")
    print(output)
    connection.disconnect()
except Exception as e:
    print(f"Koneksi ke perangkat gagal: {e}")
```

**Nama file yang disarankan:** `netmiko_device.py`

**Instalasi pustaka:**
```bash
pip install netmiko
```

**Cara menjalankan:**
```bash
python3 netmiko_device.py
```

**Penjelasan:**
- `netmiko` mempermudah koneksi ke perangkat jaringan dibanding `paramiko`;
- `send_command()` digunakan untuk menjalankan perintah *show*;
- script ini cocok untuk automasi router dan switch.

### Catatan Keamanan
Dalam automasi akses remote, beberapa hal penting yang perlu diperhatikan adalah:
- hindari menyimpan password langsung di script produksi;
- gunakan SSH key jika memungkinkan;
- batasi akses user sesuai kebutuhan;
- gunakan Telnet dan FTP hanya di lab atau simulasi;
- pastikan perangkat tujuan memang diizinkan untuk diakses.
