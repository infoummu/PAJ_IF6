# Modul 5 – Automasi Multi-Host dan Audit Jaringan dengan Bash dan Python

## Capaian Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
- memahami kebutuhan automasi pada banyak host atau perangkat jaringan;
- menggunakan tool Linux untuk audit konektivitas, layanan, dan konfigurasi secara berulang;
- membuat Bash Script untuk memeriksa banyak host secara otomatis;
- membuat Python Script untuk pengumpulan informasi jaringan multi-host;
- menyusun hasil audit jaringan sederhana dalam bentuk log atau laporan.

## Pendahuluan
Pada jaringan skala kecil, pemeriksaan konektivitas dan konfigurasi masih dapat dilakukan secara manual. Namun, ketika jumlah host, server, atau perangkat jaringan bertambah, pekerjaan manual menjadi tidak efisien dan rawan kesalahan. Administrator membutuhkan cara untuk memeriksa banyak target secara konsisten dalam waktu singkat.

Automasi multi-host merupakan langkah penting dalam administrasi jaringan modern. Dengan pendekatan ini, pemeriksaan konektivitas, port, hostname, konfigurasi IP, atau layanan tertentu dapat dilakukan serempak terhadap banyak target. Modul ini membahas penggunaan tool Linux untuk audit jaringan, lalu mengotomasi pekerjaan tersebut menggunakan Bash dan Python.

## Alat dan Bahan

- Beberapa host uji atau perangkat jaringan simulasi

## Bagian 1 – Tool Linux untuk Audit Jaringan Multi-Host

### 1. `ping`
`ping` tetap menjadi tool dasar untuk audit konektivitas ke banyak host.

**Fungsi utama:**
- mengecek host aktif atau tidak;
- mengukur respons dasar jaringan;
- menjadi tahap awal audit jaringan.

**Contoh penggunaan:**
```bash
ping -c 2 192.168.1.1
```

```bash
ping -c 2 8.8.8.8
```

**Penjelasan:**
Dalam audit multi-host, `ping` sering dijalankan berulang ke banyak alamat untuk mengetahui host mana yang aktif.

---

### 2. `nmap`
`nmap` digunakan untuk memeriksa host aktif dan port yang terbuka.

**Fungsi utama:**
- pemindaian banyak host;
- audit port layanan;
- identifikasi layanan dasar.

**Contoh penggunaan:**
```bash
nmap 192.168.1.0/24
```

```bash
nmap -sV 192.168.1.10
```

**Penjelasan:**
- `nmap 192.168.1.0/24` digunakan untuk scan subnet;
- `-sV` menampilkan versi layanan yang terdeteksi.

> Gunakan hanya pada jaringan yang diizinkan untuk praktikum.

---

### 3. `ssh`
`ssh` dapat digunakan untuk mengakses banyak host satu per satu secara otomatis melalui script.

**Fungsi utama:**
- mengambil informasi hostname;
- menjalankan command audit;
- memeriksa konfigurasi dari beberapa server.

**Contoh penggunaan:**
```bash
ssh user@192.168.1.10 "hostname"
```

```bash
ssh user@192.168.1.11 "ip addr | grep inet"
```

**Penjelasan:**
Dengan mengombinasikan `ssh` dan script, administrator dapat memeriksa banyak host tanpa login manual ke masing-masing host.

---

### 4. `grep`
`grep` digunakan untuk menyaring output audit agar hanya informasi penting yang ditampilkan.

**Fungsi utama:**
- mencari status tertentu;
- mengambil alamat IP atau hostname;
- membantu pembuatan ringkasan audit.

**Contoh penggunaan:**
```bash
ip addr | grep inet
```

```bash
grep "open" hasil_scan.txt
```

**Penjelasan:**
Dalam audit jaringan, `grep` membantu mempercepat analisis dari output yang panjang.

---

### 5. `tee`
`tee` digunakan untuk menyimpan hasil audit ke file sambil tetap menampilkannya di terminal.

**Fungsi utama:**
- dokumentasi hasil audit;
- penyimpanan log sementara;
- memudahkan pelaporan hasil praktikum.

**Contoh penggunaan:**
```bash
nmap 192.168.1.10 | tee audit_host_10.txt
```

**Penjelasan:**
Output audit dapat langsung dilihat dan juga disimpan untuk dianalisis ulang.

---

### 6. `sort` dan `uniq`
`sort` dan `uniq` berguna untuk merapikan hasil audit, terutama jika ada data berulang.

**Fungsi utama:**
- mengurutkan hasil scan;
- menghapus duplikasi data;
- membantu pembuatan laporan sederhana.

**Contoh penggunaan:**
```bash
cat daftar_host.txt | sort
```

```bash
cat daftar_host.txt | sort | uniq
```

**Penjelasan:**
Kedua perintah ini membantu memastikan daftar host atau hasil audit lebih rapi dan tidak duplikat.

---

### 7. `wc`
`wc` digunakan untuk menghitung jumlah baris, kata, atau karakter dari hasil audit.

**Fungsi utama:**
- menghitung jumlah host dalam daftar;
- menghitung jumlah hasil scan;
- membantu pembuatan statistik sederhana.

**Contoh penggunaan:**
```bash
wc -l daftar_host.txt
```

**Penjelasan:**
Perintah ini sering digunakan untuk mengetahui berapa banyak target yang akan diperiksa.

## Bagian 2 – Bash Script

Bash Script dapat digunakan untuk melakukan audit terhadap beberapa host berdasarkan daftar target dari file atau array.

### Script 1 – Audit Konektivitas Banyak Host
Script berikut melakukan ping ke beberapa host dan menampilkan statusnya.

```bash
#!/bin/bash

hosts=("192.168.1.1" "192.168.1.10" "8.8.8.8")

for host in "${hosts[@]}"; do
    if ping -c 2 "$host" > /dev/null 2>&1; then
        echo "[AKTIF] $host"
    else
        echo "[TIDAK AKTIF] $host"
    fi
done
```

**Nama file yang disarankan:** `audit_ping_multi.sh`

**Cara menjalankan:**
```bash
chmod +x audit_ping_multi.sh
./audit_ping_multi.sh
```

**Penjelasan:**
- script melakukan loop pada beberapa host;
- status tiap host ditampilkan dalam bentuk sederhana;
- dapat dikembangkan agar membaca target dari file.

---

### Script 2 – Audit Informasi Host via SSH
Script berikut mengambil hostname dari beberapa host remote.

```bash
#!/bin/bash

hosts=("192.168.1.10" "192.168.1.11")
user="user"

for host in "${hosts[@]}"; do
    echo "===== $host ====="
    ssh ${user}@${host} "hostname"
done
```

**Nama file yang disarankan:** `audit_ssh_multi.sh`

**Cara menjalankan:**
```bash
chmod +x audit_ssh_multi.sh
./audit_ssh_multi.sh
```

**Penjelasan:**
- script menggunakan `ssh` untuk mengambil informasi dari banyak host;
- sangat berguna untuk audit identitas server atau perangkat.

## Bagian 3 – Python Script

Python lebih fleksibel untuk audit multi-host karena dapat memproses daftar host, mengelola output, dan menyimpan hasil dalam struktur data.

### Script 1 – Audit Ping Banyak Host dengan Python
Script berikut melakukan pengecekan konektivitas ke banyak host menggunakan `subprocess`.

```python
import subprocess

hosts = ["192.168.1.1", "192.168.1.10", "8.8.8.8"]

for host in hosts:
    result = subprocess.run(
        ["ping", "-c", "2", host],
        stdout=subprocess.DEVNULL,
        stderr=subprocess.DEVNULL
    )

    if result.returncode == 0:
        print(f"[AKTIF] {host}")
    else:
        print(f"[TIDAK AKTIF] {host}")
```

**Nama file yang disarankan:** `audit_ping_multi.py`

**Cara menjalankan:**
```bash
python3 audit_ping_multi.py
```

**Penjelasan:**
- `subprocess.run()` digunakan untuk memanggil command Linux;
- hasil diklasifikasikan berdasarkan kode keluar perintah.

### Script 2 – Audit Host Remote dengan Paramiko
Script berikut melakukan login ke beberapa host dan mengambil hostname masing-masing.

```python
import paramiko

hosts = ["192.168.1.10", "192.168.1.11"]
username = "user"
password = "password"

for host in hosts:
    print(f"===== {host} =====")
    client = paramiko.SSHClient()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())

    try:
        client.connect(hostname=host, username=username, password=password, timeout=5)
        stdin, stdout, stderr = client.exec_command("hostname")
        print(stdout.read().decode().strip())
    except Exception as e:
        print(f"Koneksi gagal: {e}")
    finally:
        client.close()
```

**Nama file yang disarankan:** `audit_paramiko_multi.py`

**Instalasi pustaka:**
```bash
pip install paramiko
```

**Cara menjalankan:**
```bash
python3 audit_paramiko_multi.py
```

**Penjelasan:**
- script menggunakan list host sebagai target audit;
- tiap host diakses satu per satu;
- hasil hostname ditampilkan sebagai verifikasi identitas target.
