## Bagian 1 – Tool Linux yang Digunakan pada Proyek Mini Automasi Jaringan

Pada proyek mini ini, beberapa tool Linux dari modul-modul sebelumnya akan digunakan secara terpadu.

### 1. `ping`
Digunakan untuk memeriksa apakah host dapat dijangkau.

**Contoh penggunaan:**
```bash
ping -c 2 192.168.1.10
```

**Peran dalam proyek:**
Menjadi tahap awal untuk menentukan host aktif sebelum dilakukan pemeriksaan lanjutan.

---

### 2. `ssh`
Digunakan untuk mengambil informasi dari host remote.

**Contoh penggunaan:**
```bash
ssh user@192.168.1.10 "hostname && ip addr | grep inet"
```

**Peran dalam proyek:**
Mengambil hostname, alamat IP, atau informasi lain dari host yang aktif.

---

### 3. `nmap`
Digunakan untuk memeriksa port yang terbuka pada host target.

**Contoh penggunaan:**
```bash
nmap 192.168.1.10
```

**Peran dalam proyek:**
Melihat layanan dasar yang berjalan pada host target.

---

### 4. `tee`
Digunakan untuk menyimpan hasil command ke file log.

**Contoh penggunaan:**
```bash
nmap 192.168.1.10 | tee hasil_scan_10.txt
```

**Peran dalam proyek:**
Menyimpan hasil pemeriksaan ke file untuk dokumentasi dan analisis lanjut.

---

### 5. `grep`
Digunakan untuk memfilter data penting dari log.

**Contoh penggunaan:**
```bash
grep "open" hasil_scan_10.txt
```

**Peran dalam proyek:**
Memilih bagian hasil yang relevan, misalnya port terbuka atau alamat IP.

---

### 6. `date`
Digunakan untuk membuat timestamp pada log atau laporan.

**Contoh penggunaan:**
```bash
date +"%Y-%m-%d_%H-%M-%S"
```

**Peran dalam proyek:**
Membedakan hasil pemeriksaan berdasarkan waktu pelaksanaan.

---

### 7. `wc`
Digunakan untuk menghitung jumlah hasil, misalnya jumlah host aktif atau jumlah port terbuka.

**Contoh penggunaan:**
```bash
grep "open" hasil_scan_10.txt | wc -l
```

**Peran dalam proyek:**
Membuat statistik sederhana pada laporan akhir.

---

### Ringkasan Bagian 1

## Bagian 2 – Bash Script

Pada bagian ini dibuat contoh mini project sederhana menggunakan Bash Script.

### Script 1 – Audit Host Aktif dan Simpan ke Log
Script berikut mengecek beberapa host, lalu menyimpan hasilnya ke file log.

```bash
#!/bin/bash

hosts=("192.168.1.1" "192.168.1.10" "8.8.8.8")
timestamp=$(date +"%Y-%m-%d_%H-%M-%S")
logfile="audit_host_${timestamp}.log"

for host in "${hosts[@]}"; do
    if ping -c 2 "$host" > /dev/null 2>&1; then
        echo "[AKTIF] $host" | tee -a $logfile
    else
        echo "[TIDAK AKTIF] $host" | tee -a $logfile
    fi
done

echo "Log audit disimpan di $logfile"
```

**Nama file yang disarankan:** `mini_audit_host.sh`

**Cara menjalankan:**
```bash
chmod +x mini_audit_host.sh
./mini_audit_host.sh
```

**Penjelasan:**
- script mengecek beberapa host sekaligus;
- hasil audit tersimpan pada file log;
- format sederhana ini dapat digunakan sebagai dasar proyek mini.

---

### Script 2 – Audit Port dan Ringkasan Sederhana
Script berikut melakukan scan satu host dan membuat ringkasan jumlah port terbuka.

```bash
#!/bin/bash

target="192.168.1.10"
outfile="scan_${target}.txt"

nmap $target > $outfile

echo "Port yang terbuka pada $target:"
grep "open" $outfile

echo "Jumlah port terbuka:"
grep "open" $outfile | wc -l
```

**Nama file yang disarankan:** `mini_scan_port.sh`

**Cara menjalankan:**
```bash
chmod +x mini_scan_port.sh
./mini_scan_port.sh
```

**Penjelasan:**
- hasil scan disimpan ke file;
- `grep` digunakan untuk menampilkan port terbuka;
- `wc -l` menghitung total port terbuka.

## Bagian 3 – Python Script

Pada bagian ini dibuat contoh mini project sederhana menggunakan Python Script.

### Script 1 – Audit Host Aktif dan Logging dengan Python
Script berikut memeriksa beberapa host, menampilkan hasil, dan menyimpannya ke file log.

```python
import subprocess
from datetime import datetime

hosts = ["192.168.1.1", "192.168.1.10", "8.8.8.8"]
timestamp = datetime.now().strftime("%Y-%m-%d_%H-%M-%S")
logfile = f"audit_host_{timestamp}.log"

with open(logfile, "w") as file:
    for host in hosts:
        result = subprocess.run(
            ["ping", "-c", "2", host],
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL
        )

        if result.returncode == 0:
            line = f"[AKTIF] {host}\n"
        else:
            line = f"[TIDAK AKTIF] {host}\n"

        print(line.strip())
        file.write(line)

print(f"Log audit disimpan di {logfile}")
```

**Nama file yang disarankan:** `mini_audit_host.py`

**Cara menjalankan:**
```bash
python3 mini_audit_host.py
```

**Penjelasan:**
- script memeriksa konektivitas banyak host;
- hasil disimpan ke file log dengan timestamp;
- pendekatan ini lebih mudah dikembangkan dibanding Bash untuk proyek yang lebih besar.

### Script 2 – Audit Informasi Host Remote dengan Paramiko
Script berikut melakukan SSH ke host aktif dan mengambil hostname.

```python
import paramiko

hosts = ["192.168.1.10", "192.168.1.11"]
username = "user"
password = "password"

for host in hosts:
    print(f"===== {host} =====")
    client = paramiko.SSHClient()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())

    try:
        client.connect(hostname=host, username=username, password=password, timeout=5)
        stdin, stdout, stderr = client.exec_command("hostname && ip addr | grep inet")
        print(stdout.read().decode())
    except Exception as e:
        print(f"Koneksi gagal: {e}")
    finally:
        client.close()
```

**Nama file yang disarankan:** `mini_audit_paramiko.py`

**Instalasi pustaka:**
```bash
pip install paramiko
```

**Cara menjalankan:**
```bash
python3 mini_audit_paramiko.py
```

**Penjelasan:**
- script mengakses lebih dari satu host;
- hasil hostname dan alamat IP ditampilkan sebagai laporan sederhana;
- sangat cocok sebagai dasar mini project automasi jaringan.
