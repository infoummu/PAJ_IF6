# Modul 6 – Logging, Parsing Output, dan Pelaporan Automasi Jaringan dengan Bash dan Python

## Capaian Pembelajaran
Setelah menyelesaikan praktikum ini, mahasiswa diharapkan mampu:
- memahami pentingnya logging dan pelaporan dalam automasi jaringan;

Hasil automasi tersebut perlu dicatat, dianalisis, dan disajikan kembali dalam bentuk yang lebih mudah dipahami. ## Bagian 1 – Tool Linux untuk Logging, Parsing, dan Pelaporan

### 1. `tee`
`tee` digunakan untuk menyimpan output command ke file sekaligus tetap menampilkannya di terminal.

**Fungsi utama:**
- membuat log command;
- menyimpan hasil audit;
- memudahkan dokumentasi praktikum.

**Contoh penggunaan:**
```bash
ping -c 4 8.8.8.8 | tee hasil_ping.txt
```

```bash
nmap 192.168.1.10 | tee hasil_nmap.txt
```

**Penjelasan:**
Dengan `tee`, hasil command dapat langsung dilihat di layar dan juga tersimpan di file untuk analisis berikutnya.

---

### 2. `grep`
`grep` digunakan untuk mencari pola tertentu dari output atau file log.

**Fungsi utama:**
- memfilter informasi penting;
- mencari error, status, atau alamat IP;
- mengekstrak bagian tertentu dari hasil audit.

**Contoh penggunaan:**
```bash
grep "ttl" hasil_ping.txt
```

```bash
grep "open" hasil_nmap.txt
```

**Penjelasan:**
Perintah ini membantu mengambil bagian yang relevan dari log yang panjang.

---

### 3. `cut`
`cut` digunakan untuk mengambil bagian tertentu dari tiap baris berdasarkan delimiter atau posisi karakter.

**Fungsi utama:**
- mengambil kolom data;
- menyederhanakan output;
- membantu parsing sederhana dari file teks.

**Contoh penggunaan:**
```bash
echo "router1,192.168.1.1,aktif" | cut -d',' -f1,2
```

**Penjelasan:**
- `-d','` menentukan delimiter berupa koma;
- `-f1,2` mengambil kolom pertama dan kedua.

---

### 4. `awk`
`awk` digunakan untuk pemrosesan teks dan pengambilan kolom pada output command.

**Fungsi utama:**
- mengambil kolom tertentu;
- memformat ulang output;
- membuat laporan teks sederhana.

**Contoh penggunaan:**
```bash
ip addr | grep inet | awk '{print $2}'
```

```bash
ss -tuln | awk '{print $1, $5}'
```

**Penjelasan:**
`awk` sangat berguna untuk mengubah output mentah menjadi data yang lebih mudah dibaca.

---

### 5. `sed`
`sed` digunakan untuk mengubah atau membersihkan teks dari output atau file log.

**Fungsi utama:**
- mengganti teks tertentu;
- membersihkan karakter yang tidak dibutuhkan;
- mempersiapkan output sebelum dilaporkan.

**Contoh penggunaan:**
```bash
echo "Host: 192.168.1.1" | sed 's/Host: //'
```

**Penjelasan:**
Perintah ini menghapus teks `Host: ` sehingga hanya menyisakan alamat IP.

---

### 6. `sort` dan `uniq`
`sort` dan `uniq` digunakan untuk merapikan dan menghilangkan duplikasi data pada hasil audit.

**Fungsi utama:**
- mengurutkan hasil log;
- menghapus data duplikat;
- mempersiapkan data untuk ringkasan laporan.

**Contoh penggunaan:**
```bash
sort daftar_ip.txt | uniq
```

**Penjelasan:**
Sangat berguna ketika hasil parsing menghasilkan banyak data yang berulang.

---

### 7. `wc`
`wc` digunakan untuk menghitung jumlah baris atau elemen hasil audit.

**Fungsi utama:**
- menghitung jumlah host;
- menghitung jumlah port terbuka;
- menghasilkan statistik sederhana.

**Contoh penggunaan:**
```bash
grep "open" hasil_nmap.txt | wc -l
```

**Penjelasan:**
Perintah ini dapat digunakan untuk menghitung berapa banyak port yang ditemukan terbuka.

---

### 8. `date`
`date` digunakan untuk memberi cap waktu (*timestamp*) pada file log atau laporan.

**Fungsi utama:**
- menandai waktu pelaksanaan audit;
- membantu dokumentasi hasil automasi;
- memudahkan pembandingan laporan dari waktu ke waktu.

**Contoh penggunaan:**
```bash
date
```

```bash
date +"%Y-%m-%d_%H-%M-%S"
```

**Penjelasan:**
Format khusus ini sering digunakan untuk nama file log agar unik dan mudah dikenali.

## Bagian 2 – Bash Script

Bash Script dapat digunakan untuk membuat log otomatis dan menghasilkan ringkasan sederhana dari hasil audit jaringan.

### Script 1 – Logging Hasil Ping ke File
Script berikut menjalankan ping dan menyimpan hasilnya ke file log yang diberi timestamp.

```bash
#!/bin/bash

target="8.8.8.8"
timestamp=$(date +"%Y-%m-%d_%H-%M-%S")
logfile="ping_${timestamp}.log"

ping -c 4 $target | tee $logfile

echo "Log disimpan di $logfile"
```

**Nama file yang disarankan:** `log_ping.sh`

**Cara menjalankan:**
```bash
chmod +x log_ping.sh
./log_ping.sh
```

**Penjelasan:**
- `timestamp` digunakan agar nama file unik;
- `tee` menyimpan hasil dan tetap menampilkannya di terminal.

---

### Script 2 – Parsing Port Terbuka dari Hasil Nmap
Script berikut melakukan scan dan hanya menampilkan port yang terbuka.

```bash
#!/bin/bash

target="192.168.1.10"
outfile="hasil_nmap.txt"

nmap $target > $outfile

echo "Port yang terbuka pada $target:"
grep "open" $outfile | awk '{print $1, $3}'
```

**Nama file yang disarankan:** `laporan_nmap.sh`

**Cara menjalankan:**
```bash
chmod +x laporan_nmap.sh
./laporan_nmap.sh
```

**Penjelasan:**
- hasil scan disimpan ke file;
- `grep` dan `awk` digunakan untuk membuat ringkasan port yang terbuka.

## Bagian 3 – Python Script

Python dapat digunakan untuk membaca output command, memisahkan data penting, lalu menyimpannya dalam format laporan yang lebih terstruktur.

### Script 1 – Logging Hasil Ping dengan Python
Script berikut menjalankan `ping`, menyimpan output, dan menuliskan hasil ke file log.

```python
import subprocess
from datetime import datetime

target = "8.8.8.8"
timestamp = datetime.now().strftime("%Y-%m-%d_%H-%M-%S")
logfile = f"ping_{timestamp}.log"

result = subprocess.run(["ping", "-c", "4", target], capture_output=True, text=True)

with open(logfile, "w") as file:
    file.write(result.stdout)

print(result.stdout)
print(f"Log disimpan di {logfile}")
```

**Nama file yang disarankan:** `log_ping.py`

**Cara menjalankan:**
```bash
python3 log_ping.py
```

**Penjelasan:**
- Python menyimpan hasil command ke variabel;
- file log ditulis menggunakan `open()` dan `write()`;
- pendekatan ini lebih fleksibel untuk pengembangan lebih lanjut.

---

### Script 2 – Parsing Hasil Port Aktif dengan Python
Script berikut menjalankan `ss -tuln`, lalu hanya mengambil baris yang menunjukkan port listen.

```python
import subprocess

result = subprocess.run(["ss", "-tuln"], capture_output=True, text=True)
lines = result.stdout.splitlines()

print("Port atau socket yang aktif:")
for line in lines[1:]:
    parts = line.split()
    if len(parts) >= 5:
        proto = parts[0]
        local_address = parts[4]
        print(f"Protokol: {proto} | Alamat lokal: {local_address}")
```

**Nama file yang disarankan:** `parse_ss.py`

**Cara menjalankan:**
```bash
python3 parse_ss.py
```

**Penjelasan:**
- output `ss` dipisah menjadi beberapa baris;
- setiap baris dipecah menjadi kolom menggunakan `split()`;
- hanya data yang dibutuhkan yang ditampilkan ulang.
